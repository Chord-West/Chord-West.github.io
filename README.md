# 김현서 개발자 포트폴리오

https://chord-west.github.io/

고객 화면과 운영 어드민을 연결한 개발 경험을 소개합니다. 화이트·블랙과 오렌지레드 포인트, 왼쪽 기준선을 공유하는 넓은 2열 레이아웃, 실제 서비스 화면 전환을 사용합니다.

## 기능

- 고객 화면 / 운영 화면 전환
- 프로젝트별 성과 요약과 펼쳐 읽는 상세 사례
- 이미지 확대, 이전·다음 탐색과 키보드 닫기
- 모바일 메뉴, 인쇄 / PDF 저장

## 파일

`index.html`: 내용. `style.css`: 디자인과 반응형. `script.js`: 인터랙션. `portfolio.woff`: 제공된 HTML의 한글 폰트. `clash-regular.woff2`, `clash-medium.woff2`: Fontshare Clash Grotesk. `.jpg`: 제공된 포트폴리오의 실제 서비스 화면.

별도 빌드가 필요 없는 정적 사이트입니다. GitHub Pages는 main 브랜치의 루트 폴더를 사용합니다.

로컬 확인: 이 폴더에서 `python3 -m http.server 8765`를 실행하고 http://localhost:8765 에 접속합니다.
